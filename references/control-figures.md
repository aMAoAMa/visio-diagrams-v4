# 控制论文插图的建模与版式

## 从公式到连线

以示例关系 e = r − m、u = C(s)e、y = G(s)u、m = H(s)y 为例。r 进入求和点的正端，m 回到负端；C 的输出是 u，G 的输出是 y。先沿正向通路画到 y，再从 y 的取样点回接 H。若 H 为单位映射，可按正文约定直接反馈 y。正反馈、双自由度或开环模型均按各自方程建图。

求和点用小圆，符号紧靠各入线；取样点用实心点，同一支路两端使用一致的信号名。无关导线交叉时优先绕线，保留交叉时去掉节点点记号。反馈路径通常沿外围，回线保持与正向信号相同的线型。虚框用于子系统分组时，框名和边界端口交代内外关系。颜色仅用于有意义的区分。

## 遇到不同系统时如何改图

| 正文关系 | 如何绘制 | 从图上复核 |
|---|---|---|
| 状态反馈与估计 | 对象输出 y 与实际施加的 u 按估计器方程送入观测器，估计值 x̂ 送往控制律。已知的状态测量直接接入对应端。 | 遮住对象内部，逐个判断控制器输入能否从图中取得；检查饱和前命令与实际输入取用位置。 |
| 串级与前馈 | 外环输出接到内环设定端；分别取回内、外环的被控量。前馈在正文指定的结合点并入。 | 分别读出两个误差。输入扰动、输出扰动和测量噪声分别核对注入端。 |
| MIMO 与分布式控制 | 依据正文用向量或分量线；在矩阵块标出必要维度。网络边用约定明确的发送端和接收端。 | 各端口维数能否匹配？通信边方向能否按作者定义还原邻接关系？ |
| 滚动优化 | 在优化器边界标出参考、当前估计及已知约束；若正文按滚动时域实施，仅首个控制动作发给对象。 | 预测序列、当前施加量、下一拍更新分别可定位。离线模型和在线数据通路可区分。 |
| 采样与事件触发 | 以 k 或 t 为统一基准，标出观测、计算、传输和保持生效的时刻；不同速率按已知周期标明。 | 同拍与跨拍更新有无混淆？未给定固定周期的事件有无被误画为等间隔？ |
| 性能对比 | 时响写明时间单位，区分设定与输出；Bode 幅相图共享频率轴并注明 Hz 或 rad/s。相平面标状态及方向。 | 工况、初值、单位、时间窗是否可比？误差带或约束线是否有定义？ |

## 可追溯的版式起点

IEEE Control Systems Letters 使用双栏模板。先从实际模板取得单栏或通栏宽度，再选布局。[L-CSS 作者说明](https://ieeecss.org/publication/ieee-control-systems-letters/author-information)

缺少指定模板时，可先按 89 mm 单栏试排，标签按成图约 9–10 pt 试读。该起点取自 Proceedings of the IEEE 的图表指南；具体期刊的尺寸和分辨率以其投稿规范为准。检查灰度时，比较同类信号在没有颜色提示时能否辨认。[IEEE 图表指南](https://proceedingsoftheieee.ieee.org/resources/guidelines-for-figures-and-tables/)

实际例图 Extended Data Fig. 2 将扰动接入执行模块之后，并在测量支路表示相机与星敏感器的选择。可借鉴的是将扰动入口和测量选择放在它们实际生效的位置。其他系统应从自身方程确定这些位置。[原论文图及图注](https://arxiv.org/pdf/2408.10994#page=36)
